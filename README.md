# Kent Kim — speaker site

국제학교 강연 제안용 개인 사이트. **deother 와는 별개 사이트다** — 게임 회사 URL 을
학교에 보내면 첫인상이 어긋나서 따로 만들었다.

- `index.html` 하나뿐이다. 빌드 도구 없음. 인라인 CSS/JS.
- 폰트만 Google Fonts (Newsreader · IBM Plex Sans · IBM Plex Mono).

## 별도 레포로 떼어내는 법

지금은 작업 보존을 위해 deother 레포 안에 있다. 독립 사이트이므로 옮긴다:

```bash
mkdir ~/kentkim-speaker && cp index.html README.md ~/kentkim-speaker/
cd ~/kentkim-speaker && git init && git add -A && git commit -m "init"
# GitHub 에 새 레포 만들고 push → Vercel 에 새 프로젝트로 연결
```

Vercel 은 설정이 필요 없다. 정적 파일이라 그대로 뜬다.

### 이메일 노출 방지 (2026-08-23)

**HTML 소스에 평문 주소를 두지 않는다.** 스팸 수집 봇은 대부분 JS 를 실행하지 않고
소스에서 `@` 패턴만 긁어간다. 그래서 주소를 **JS 로 조립**한다:

```js
const user = ["kent","kim"].join("");
const host = ["gmail","com"].join(".");
const addr = user + String.fromCharCode(64) + host;   // @ 도 문자코드로
```

- 소스에 `kentkim@gmail.com` 도 `@gmail` 도 **한 번도 나오지 않는다**(코드로 확인).
- 사람에겐 그대로 보이고 클릭하면 메일이 열린다. **「주소 복사」 버튼**도 같이 붙였다.
- **JS 를 끈 방문자용 `<noscript>` 대체 문구**가 있다 — 디아더 사이트로 안내한다.
- ⚠️ **문구를 고칠 때 주소를 평문으로 되돌리지 말 것.** 한 번 긁히면 되돌릴 수 없다.

**남은 권고: 도메인 주소를 따로 파는 것.**
지금은 개인 gmail 이라 ① 학교 담당자에게 덜 공식적으로 보이고 ② 스팸이 붙으면
개인 메일함이 오염된다. `speaking@deother.com` 같은 전용 주소를 만들어 gmail 로
포워딩하면 둘 다 해결된다 — 주소만 주시면 한 줄 고치면 된다.
